## 核心要点

论文研究了如何利用现成的大语言模型（GPT-3.5和GPT-4）来解决模式匹配问题，提出了4种不同的"任务范围"（Task Scopes）提示工程方法：

1. **1-to-1**: 每次比较单个源属性和单个目标属性
2. **1-to-N**: 单个源属性与所有目标属性
3. **N-to-1**: 所有源属性与单个目标属性（最佳单一方法）
4. **N-to-M**: 所有源属性与所有目标属性

**主要发现**:
- LLM在零样本设置下可以有效进行模式匹配
- 上下文信息量与性能呈非线性关系（过少或过多都不好）
- GPT-4 + (1-to-N, N-to-1)组合方法达到最佳效果：召回率~83%，验证工作量<10%
- 相比传统字符串相似度方法，F1分数提升最高达0.245
